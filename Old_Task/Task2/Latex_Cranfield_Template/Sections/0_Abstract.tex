\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}

This report outlines the operational strategy for Group Chenonceau regarding the Digital Engineering Design Group Project. Following the first group meeting, this document defines the allocation of roles and responsibilities among members (John Hoarau, Martin Harambat, Pierre Bédrune, and Clémence-Philomène Hinot) based on the strengths identified in Task 1 \cite{hoarauTask1, harambatTask1}. Furthermore, it establishes the project management methodology, selecting specific tools for communication and task tracking, and presents a provisional GANTT chart timeline to ensure all module deadlines are met \cite{phillips2025brief}.
