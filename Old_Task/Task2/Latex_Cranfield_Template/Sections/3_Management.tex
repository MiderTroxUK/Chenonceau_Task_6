\section{Project Management Strategy}

\subsection{Methodology}
The group will adopt an Agile methodology as required by the module brief \cite{phillips2025brief}. This will involve:
\begin{itemize}
    \item \textbf{Weekly Scrums:} Short meetings to review progress on the current "Sprint" (Task).
    \item \textbf{Stand-ups:} Ad-hoc updates via messaging to address immediate blockers.
    \item \textbf{Iterative Development:} Focusing on delivering functional components for each Task deadline rather than attempting a "big bang" delivery at the end.
\end{itemize}

\subsection{Tools}
The group has selected the following free project management tools:

\begin{itemize}
    \item \textbf{Communication:} \textit{Cranfield Teams} for instant messaging, voice meetings, and screen sharing.
    \item \textbf{Task Management:} \textit{Notion}. A Kanban board will be used to track tasks through the "To Do", "Doing", and "Done" stages, as well as a Gantt chart to meet our deadlines, and some issue attributions to divide tasks and track the evolution of each member. This addresses the organisational weaknesses identified by the ENTP members \cite{harambatTask1}.
    \item \textbf{File Storage:} \textit{Cranfield OneDrive}. A shared drive has been established to store all reports, research papers, and assets.
    \item \textbf{Version Control:} \textit{GitHub}. All code related to the optimisation algorithms and software development will be hosted in a private repository.
\end{itemize}
