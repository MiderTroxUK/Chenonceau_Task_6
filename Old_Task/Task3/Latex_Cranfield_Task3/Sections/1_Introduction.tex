\section{Introduction}
This report investigates unconstrained and constrained nonlinear optimisation techniques. Specifically, it compares the performance of \textbf{Particle Swarm Optimisation (PSO)} and \textbf{Simulated Annealing (SA)}. These algorithms are applied to three distinct engineering problems:
\begin{enumerate}
    \item \textbf{Two-Bar Plane Truss Design} (Constrained, Multi-objective)
    \item \textbf{Sensor Calibration} (Unconstrained, Curve fitting)
    \item \textbf{Gear Train Design} (Constrained, Discrete/Integer optimization)
\end{enumerate}
