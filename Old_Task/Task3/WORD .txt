2.1 Method 1: Particle Swarm Optimisation (PSO)

The Particle Swarm Optimisation (PSO) is a stochastic optimisation technique inspired by the social behaviour of birds. A population of candidate solutions moves through the domain. Through several time steps, each particle adjusts its position based on its personal best and on the global best. This allows the algorithm to converge to a solution that matches a criterion. [1]

2.1.1 Multi-objective algorithm

2.1.1.1 Description

The multi-objective PSO finds Pareto-optimal solutions using a selection based on dominance and diversity [2]. It presents advantages such as an ease of implementation, few parameters to tune, and a good application for nonlinear problems; but also, limitations such as a possible too early convergence, a sensitivity to parameters settings, and no guarantee of global optimum [1].

The MOPSO-CD (Multi-Objective Particle Swarm Optimisation with Crowding Distance) is an advanced an extension of the PSO [3]. This particular algorithm was chosen from a list of other solution on the base of specific criteria (Appendix 8.1). Its key features are:
	Crowding distance-based leader selection,
	External archive management,
	Tournament selection,
	Enhanced exploration.

2.1.1.2 Performance metrics

Metrics are used to measure the performance of the algorithm. We have selected some of the most common criteria:
	The best value per objective which tracks the minimum value achieved for each objective function at every generation,
	The Pareto front size evolution which tracks how many solutions are on the Pareto front at each generation,
	The normalized convergence which compares both objectives normalized to [0, 1].

3.1 Problem description [4]

The Two-Bar Truss problem is composed by two diagonal bars (of aluminium here) connected on a node and are fixed at two upper point (Figure 1). On the central node we applied a vertical strength. This force represents the external load that the structure must support. We look for the vertical displacement of the node.
 
Figure 1: Two-bar plane truss [4]

There are two design variables which are the position of the joints 1 and 2. They are defined by the two equations: f1 the structural weight truss, and f2 the displacement of joint 3.
f_1\left(x\right)=2\rho hx_2\sqrt{1+x_1^2}
f_2\left(x\right)=\frac{Ph\left(1+x_1^2\right)^{1.5}\sqrt{1+x_1^4}}{2\sqrt2Ex_1^2x_2}
f_1 (x)=2ρhx_2 √(1+x_1^2 )
f_2 (x)=(Ph(1+x_1^2 )^1.5 √(1+x_1^4 ))/(2√2 Ex_1^2 x_2 )

These functions are constrained by two stress constraints functions g1 (tension) and g2 (compression).
g_1\left(x\right)=\frac{P\left(1+x_1\right)\sqrt{1+x_1^2}}{2\sqrt2x_1x_2}-\sigma_0\le0
g_2\left(x\right)=\frac{P\left(-x_1+1\right)\sqrt{1+x_1^2}}{2\sqrt2x_1x_2}-\sigma_0\le0

3.2.2 Penalty function

Pymoo library already contains constraint handling with constraint violation measures during the selection process. For the multi-objective problem, it uses the Pareto ranking. To study how the penalty strength affects convergence and feasibility, explicit penalty terms will be added [2].
F_{penalised}=f(x)+k\ast\sum\left(max\left(0,g_i(x)\right)^2\right)
With: k the penalty factor

Considering this equation, a penalty will be applied when the maximum between 0 and gi is gi so the constraint is violated. This is realised with the following loop where the penalty factor is fixed to 10 billion. If the penalty factor is large the algorithm avoids infeasible solutions quickly. While, if the penalty factor is small the algorithm may explore infeasible regions longer.

Method 2 : Solid Annealing

Problem description: 
The Simulated Annealing is an optimization method inspired by the annealing process in metallurgy. The algorithm explores the search space and accepts neighbouring solutions. In this algorithm, ameliorations are always accepted, and degradations are accepted with a probability. The probability decreases step after step (decreasing temperature). At the beginning, this acceptance mechanism helps to escape local minima. Afterwards, at the end of the process, the algorithm converges to a global minimum.
Cost function:
On this method we use this function for decide if a worst solution can be accepted: $$P(\text{acceptance}) = e^{-\frac{E_{new} - E _{actual}{T}}$$
$E _{actual}: Actual energy
E_{new}: The new worst energy
P(\text{acceptance}): the probability to accept E_{new}
T: temperature parameter 
Every iteration the temperature $T$ decrease of cooling_rate:
$$T *= cooling_rate$$

SSE = ∑▒(T_{measured,i} - T_{model,i}  )^2

Problem 4: Gear Train Design

Problem description
The objective of this exercise is to choose a gear train design that achieves a specific transmission ratio.
We would define the gear train with four gears with the numbers of teeth N1, N2, N3, N4
The target transmission ratio is: R=(N2⋅N4)/(N1⋅N3)
Here, the target transmission ratio will be randomly chosen: R_(t arg⁡e t)=1/6.931≈0.1142793
And each gear must have an integer number of teeth between 12 and 60.
The problem is difficult because the search space is discrete and nonlinear, meaning classical optimization cannot be used directly.
Therefore, tow heuristic optimization algorithms will be tested: 
	Particle Swarm Optimization (PSO)
	Simulated Annealing (SA)
The goal is to compare their performance and their behavior on this discrete optimization problem.
Cost function
The cost function measures the error between the achieved ratio and the target ratio:
f(N_1,N_2,N_3,N_4 )=|(N_1×N_3)/(N_2×N_4 )-R_(t arg⁡e t) |
A good solution is one where this error approaches zero.
Sources
Course material on PSO and Simulated Annealing
Methodology
Particle Swarm Optimization:
It simulates a swarm of particles exploring the search space. Each particle represents a potential gear combination [N_1,N_2,N_3,N_4].
Particles move according to:
	Their own best-found solution
	The best solution found by the swarm
Positions are rounded to integers to satisfy the gear teeth constraint as we can’t make gears with an odd number of teeth.
We store the best error at each iteration to generate a convergence curve like we did for the SA.
Simulated Annealing:
It explores the space by randomly perturbing the current solution. It accepts worse solutions with a probability depending on analogy to a temperature parameter:
	With high temperature goes a wide exploration
	Low temperature goes a convergence around a good solution
The algorithm stops when the temperature becomes very low. We record both the current energy and the best energy to produce a convergence curve.

Explanations
Why PSO succeeds
	PSO is particularly effective in structured continuous search spaces, even with integer rounding.
	The particles rapidly converge to the correct ratio because the cost function is smooth.
	Global and personal best mechanisms guide the search efficiently.
Why SA fails
	The gear train problem is very sensitive: small changes in N_i produce large jumps in the ratio.
	SA explores randomly and relies on thermal acceptance, which:
	Moves too chaotically
	Does not exploit promising regions enough
	Requires much slower cooling to perform well
	SA found a physically valid gear set but not even close to the desired ratio.
Conclusion
PSO is clearly the superior method for this task. It finds a nearly perfect solution extremely fast, while SA remains stuck far away from any optimal region.
For a future study, SA could be improved by:
	Reducing the cooling rate from 0.99 to 0.90 for example
	Using a smarter neighbour generator
	Introducing integer-specific heuristics
But in its current form, SA is not suitable for this optimisation problem.
