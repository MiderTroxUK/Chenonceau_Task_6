Objective: Minimising the surface of the cooling surface

Problem information:
\begin{itemize}
	\item Design variables:
		\begin{itemize}
			\item fixed volume
			\item $r_0$ to $r_m$
		\end{itemize}
	\item Constraint:
		\begin{itemize}
			\item hyperboloid
		\end{itemize}
	\item 8 simulations:
		\begin{itemize}
			\item 1 imposed
			\item x simulations with radii fixed and heights which vary
			\item x simulations with height fixed and radii which vary
			\item x simulations both heights and radii vary
		\end{itemize}
	\item run 3 algorithms on each simulation: PSO, SA, and BFGS
\end{itemize}


Other information:
\begin{itemize}
	\item hyperbolic regression with 3 points: $r_0$, $r_{m/2}$, $r_m$
	\item new constraint: $r_mi$ need to be greater than $r_{m/2}$ and to be lower than $r_m$
	\item usually $r_0$ < $r_m$
	\item $r_0$ and $r_m$ fixed arbitrary
	\item calculate the volume at each step of each algorithm
	\item to ensure the respect of the fixed volume we will use a Penalty function
	\item continuous problem
\end{itemize}

\subsection{Simulated Annealing method}

\subsubsection{Principle}

Simulated Annealing is an optimisation method inspired by the annealing process in metallurgy \cite{task3_chenonceau}. The algorithm explores the search space by accepting neighbouring solutions according to a probabilistic criterion: improvements are always accepted, while degradations are accepted with a probability that decreases over time (decreasing temperature). This acceptance mechanism helps escape local minima at the beginning, then allows the algorithm to converge towards a global minimum \cite{task3_chenonceau}.

\subsubsection{Acceptance Criterion (Metropolis)}

The probability of accepting a worse solution is given by:

\begin{equation}
P(\text{acceptance}) = e^{-\frac{E_{\text{new}} - E_{\text{actual}}}{T}}
\end{equation}

where $E_{\text{actual}}$ is the current energy, $E_{\text{new}}$ is the energy of the new solution, and $T$ is the temperature parameter \cite{task3_chenonceau}.

\subsubsection{Cooling Schedule}

At each iteration, the temperature decreases according to:

\begin{equation}
T = T \times \alpha
\end{equation}

where $\alpha$ is the cooling rate \cite{task3_chenonceau}.

\subsubsection{Key Parameters}

The SA algorithm requires the following parameters:
\begin{itemize}
    \item \textbf{$T_{\text{initial}}$}: Initial temperature (controls exploration intensity)
    \item \textbf{$\alpha$ (cooling\_rate)}: Cooling speed (typically 0.95--0.999)
    \item \textbf{$T_{\text{min}}$}: Stopping temperature
\end{itemize}

\subsubsection{Multi-Objective Strategy (Weight Scalarisation)}

SA is inherently a mono-objective algorithm. To solve bi-objective problems, a scalarisation approach transforms the problem into a single objective function using a weighted sum:

\begin{equation}
E(x) = w_1 \cdot f_1(x) + w_2 \cdot f_2(x) + \sum_{i} \lambda_i \cdot \max(0, g_i(x))
\end{equation}

where $w_1 + w_2 = 1$ and $\lambda_i$ are penalty coefficients for constraint violations. To approximate a Pareto front, multiple independent runs are performed with weights $w_1$ uniformly distributed between 0.005 and 0.995 \cite{task3_chenonceau}.
