\subsubsection{Problem Definition --- \texttt{cooling\_tower.py}}
\label{app:cooling_tower}
This module defines the geometric primitives (frustum surface area, volume, slant height) and the \texttt{CoolingTowerProblem} class which encapsulates the decision variable mapping and cost function for all eight study cases.

\clearpage
\subsubsection{Solver Orchestrator --- \texttt{solver.py}}
\label{app:solver}
The orchestrator script constructs each study case, initialises the geometry, and dispatches each algorithm wrapper uniformly. It also generates convergence plots, profile comparisons, and summary metrics.
\lstinputlisting[language=Python, caption={Solver Orchestrator (\texttt{solver.py})}, label={lst:solver}, basicstyle=\ttfamily\scriptsize, breaklines=true, numbers=left, numberstyle=\tiny\color{gray}, frame=single, tabsize=4]{../Task6/Solver/solver.py}

\clearpage
\subsubsection{BFGS Implementation --- \texttt{bfgs.py}}
\label{app:bfgs}
The BFGS quasi-Newton implementation, including inverse Hessian approximation updates, Armijo line search, and numerical gradient computation via finite differences.
\lstinputlisting[language=Python, caption={BFGS Implementation (\texttt{bfgs.py})}, label={lst:bfgs}, basicstyle=\ttfamily\scriptsize, breaklines=true, numbers=left, numberstyle=\tiny\color{gray}, frame=single, tabsize=4]{../Task6/BFGS/bfgs.py}

\clearpage
\subsubsection{PSO Implementation --- \texttt{pso.py}}
\label{app:pso}
The Particle Swarm Optimisation implementation, including swarm initialisation, velocity updates, boundary handling, and convergence tracking.
\lstinputlisting[language=Python, caption={Particle Swarm Optimisation (\texttt{pso.py})}, label={lst:pso}, basicstyle=\ttfamily\scriptsize, breaklines=true, numbers=left, numberstyle=\tiny\color{gray}, frame=single, tabsize=4]{../Task6/PSO/pso.py}
